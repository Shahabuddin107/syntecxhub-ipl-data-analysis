# 🏏 IPL Official Analytics Hub (2008 – 2026)

A full-stack cricket analytics web application built with Python, Streamlit, and SQLite. Features deep-dive metrics on all 10 IPL franchises, phase-by-phase scoring rates, stadium dynamics, player head-to-head records, and a statistical match-outcome predictor.

## 🛠️ Tech Stack
- **Frontend & Dashboard:** Streamlit, Seaborn, Matplotlib
- **Backend & Database:** SQLite3, SQL Relational Architecture
- **Data Manipulation:** Pandas, NumPy
- **Deployment:** Streamlit Cloud, GitHub

## 📊 Core Features
- **All-Time Standings & Titles:** Franchise win rates, matches played, and championship trophy records.
- **Phase Breakdown Analysis:** Over-by-over scoring dynamics across Powerplay (1-6), Middle (7-15), and Death Overs (16-20).
- **Venue & Stadium Insights:** Batting 1st vs Chasing win percentages and average first-innings scores across major venues.
- **Superstar Head-to-Head:** Comprehensive batting and bowling career comparisons (Runs, Strike Rates, Boundaries).
- **Statistical ML Outcome Predictor:** Real-time win probability estimation based on phase run rates, historic franchise strength, and toss conditions.
